# Marlon Acosta Roa — Bilingual Personal Portfolio

A responsive personal portfolio in Spanish and English, built with HTML5, CSS3, and JavaScript.

Live website: https://marlonacosta22.github.io/Proyecto-personal/

## Features

- Home, About, Skills, Resume, Projects, and Contact sections.
- ES/EN switch that translates visible content, metadata, image descriptions, and navigation labels.
- Responsive navigation with keyboard support.
- A documented project: this portfolio, with its technology stack and a real browser preview.
- Translation reflection and AI tool disclosure in NOTES.md.

## Files

- index.html: page structure and Spanish fallback content.
- style.css: layout, responsive styles, and reduced-motion support.
- script.js: language dictionaries, navigation, and skill bars.
- images/portfolio-preview.jpg: screenshot of the English home page.
- NOTES.md: draft reflection answers and declared tools.

## Run locally

Open index.html in a browser, or serve the repository with a local static web server. No build tools or package installation are required.

## Publication

GitHub Pages publishes the main branch from the repository root. The site uses relative asset paths so that it works under the Proyecto-personal subdirectory.

## Privacy and tools

Only professional contact information and a general city location are displayed. No phone number, government ID, home address, or birth date is included. OpenAI Codex assisted with this revision; see NOTES.md for details and the student's remaining personal review tasks.
